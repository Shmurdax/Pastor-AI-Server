Video Ingestion

Upload video or audio files of any common type (MP4, MOV, MKV, WebM, M4A, MP3, WAV, AAC, FLAC, and others). The original file is stored for later reference. Whisper then transcribes the audio with timestamps, the transcript is normalized to drop fillers, channel CTAs, and isolated talk that is not about Christianity, the Bible, or social ideas and issues, and the remaining timestamped lines are chunked into Qdrant.

You can drop a whole folder or hundreds of files (500+) at once. Each file is uploaded in 2 MB pieces so Cloudflare does not close the connection on large sermons. Whisper runs on CPU so it does not compete with the chat GPU model for VRAM — a long sermon can take a while. Refresh this page to watch job progress.
